2. Alcance y datos que trata Queens

La aplicación actual no tiene cuentas ni inicio de sesión, y no solicita nombres, correo, identificadores de Discord ni permisos del Embedded App SDK. La integración actual tampoco recibe ni almacena datos de perfil de Discord. Si esto cambia, esta política debe actualizarse antes de activar la nueva integración.

  • Datos de partida: identificador aleatorio de partida, tamaño, tablero, regiones, estado, movimientos, ajustes y marcas de tiempo necesarios para continuar y validar el juego.
  • Récords: tamaño del tablero, tiempo empleado, número de movimientos y fecha. La clasificación es visible para quienes consultan el Servicio; no incluye un nombre de jugador ni un identificador de cuenta.
  • Datos técnicos: al realizar conexiones web, Cloudflare puede tratar direcciones IP, datos de solicitud, registros de seguridad y otros metadatos técnicos conforme a sus propias condiciones y políticas. El código de Queens no utiliza estos datos para crear perfiles.

3. Finalidades y bases jurídicas

Tratamos los datos de partida para prestar las funciones solicitadas, guardar el estado de las partidas en el servidor y validar la partida (ejecución del servicio solicitado). Tratamos los récords para mantener y mostrar la clasificación. Los datos técnicos pueden ser tratados por el proveedor para prestar, proteger y mantener su infraestructura, conforme a sus condiciones y a la normativa aplicable. No usamos los datos para publicidad personalizada ni vendemos datos personales.

4. Proveedores y transferencias

Queens se aloja en Cloudflare Pages y utiliza Cloudflare Pages Functions y D1 para procesar y almacenar partidas y récords. Cloudflare actúa según los servicios contratados y sus propios términos de privacidad. La infraestructura puede implicar tratamiento fuera del Espacio Económico Europeo; consulta la política de privacidad de Cloudflare y su acuerdo de tratamiento de datos para conocer las salvaguardas vigentes. También podremos comunicar datos cuando lo exija la ley o sea necesario para proteger derechos y seguridad.

5. Conservación y borrado

La configuración actual no aplica una caducidad automática: las partidas y los récords se conservan en D1 hasta que se eliminen manualmente o se elimine la base de datos. No hay una función de borrado individual en la aplicación. Puedes solicitar ayuda en el correo de contacto; facilita el identificador aleatorio de partida si solicitas localizarla. Los récords no contienen identificador de partida, por lo que no siempre es posible atribuir o borrar una entrada individual. Los plazos de registros técnicos de Cloudflare dependen de ese proveedor.

6. Cookies y almacenamiento local

El código actual de Queens no instala cookies de publicidad o analítica ni utiliza almacenamiento local del navegador para crear perfiles. El navegador, Cloudflare o Discord pueden usar tecnologías técnicas necesarias para prestar y proteger sus propios servicios, sujetas a sus avisos de privacidad. Este apartado debe revisarse si se incorporan analítica, publicidad u otras tecnologías no esenciales.
